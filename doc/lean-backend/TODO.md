# Lean backend: open-work register

This file lists the open work on the Lean backend. Each row gives the
item, the record or file it comes from, a price (S, M or L, the sizing
the dated records use) and its provenance: [USER date] where an operator
ruling created or shapes the item, [AGENT] otherwise. The reasoning
lives in the cited records; the index of all records is
[RECORDS.md](RECORDS.md).

Rules for this file:
- Item numbers are stable. Other repositories cite them; a number is
  never reused or renumbered.
- An item leaves the table in the commit that discharges it, and moves to
  "Closed items" at the bottom with a link to the record that closed it.
- Every row was re-checked against the source at `2e54ff0` on 2026-10-03
  (by reading code and records; no build). A claim that could not be
  checked says so.
