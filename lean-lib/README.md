# LemLib — the Lean 4 runtime for Lem-generated code

Code generated by `lem -lean` imports this library: the `LemOrdering`
comparison type, comparator-keyed set/finite-map operations, numeric
and string bridges, and the supply-threading split (`supplySplit` — a
plain def; the library declares ZERO axioms, and generated code
carries none; see the module docstring and the HISTORY notes in
`LemLib.lean`).

Build: `lake build` (toolchain per `lean-toolchain`). Property tests:
`LemLibTest.lean`.

Documentation for the backend that targets this library:
[`doc/lean-backend/README.md`](../doc/lean-backend/README.md).
